# Tech Abdullah Portfolio

Static portfolio site for Malik. Publish the contents of this folder to the
site root for `https://techabdullah.site/`.

## Launch checklist

- Replace `assets/profile-placeholder.svg` with a current, optimized portrait.
- Add the real CV as `assets/cv.pdf` and verify both download links.
- Replace all six project placeholders, descriptions, categories, and `#` demo /
  GitHub links with real work.
- Verify the About counters (3,000+ students, 5+ years, 50+ projects, and 30+
  clients) against current figures.
- Replace the four explicitly labeled placeholder testimonials with approved
  client quotes, names, and roles.
- Replace the example email, phone number, and location in the About and Contact
  sections.
- Update GitHub, LinkedIn, X, and CodePen profile links to the correct accounts.
- Replace `YOUR_FORM_ID` in the Formspree endpoint in `index.html` with the
  production form ID and submit a test message.
- Confirm `techabdullah.site` is the production canonical domain. If it changes,
  update canonical, Open Graph/Twitter URLs, `robots.txt`, and `sitemap.xml`.

## Image optimization

- Compress the replacement profile portrait; use a correctly sized WebP or AVIF
  image when possible.
- Compress/crop each real project screenshot to its displayed aspect ratio and
  serve WebP or AVIF variants.
- The included SVG placeholders are small vector files and do not need further
  compression.
